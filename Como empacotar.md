Ver o que mudou no projeto  
`git status`

Adicionar todas as mudanças  
`git add .`

Criar o commit (salva localmente)  
`git commit -m "release 1.0.21"`

Criar a tag da versão  
`git tag v1.0.21`

Enviar commits para o GitHub  
`git push`

Enviar a tag para o GitHub  
`git push origin v1.0.21`

Build + GitHub Release automática  
`npm run release`
